# Emotional Timeline

> セクションは「情報の単位」ではなく **「感情の単位」**。
> 実装で迷ったときは、そのセクションが担当する感情に立ち返って判断する。

```
Darkness → Curiosity → Discovery → Trust → Possibility → Confidence → Action
```

| 感情 | 担当セクション | 明度 |
|---|---|---|
| **Darkness** | Loading | `#090909` |
| **Curiosity** | Hero | `#090909` |
| **Discovery** | Vision | `#090909` |
| **Trust** | What We Can Do | `#2F2F2F` |
| **Possibility** | Buy | `#F2F2F2` |
| **Confidence** | Sell / Find | `#FFFFFF` / `#CFCFCF` |
| **Action** | CTA | `#090909` |

**明度と感情が同じ向きに進む。** 暗闇から始まり、確信で最も明るくなり、行動の直前で静けさへ戻る。
色の設計([Color System](./01-design-system.md#3-color-system))は、この感情曲線を視覚化したもの。

---

## Darkness — Loading

**作りたい状態**: 何も見えない。しかし「何かがある」と感じる。

暗闇は「無」ではなく **「まだ見えていない」**。この違いがブランドの出発点になる。
ここで焦らせない。プログレスバーを置かないのは、**急がせないことがForesightの態度**だから。

**次への橋渡し**: 目の中に入り、視界が開ける直前で終わる。

## Curiosity — Hero

**作りたい状態**: 「この会社は車を普通とは違う視点で見ている」と直感する。

説明で納得させない。**説明過多はCuriosityを殺す。** 分かってしまったら、その先を見る理由が消える。
Heroが与えるのは「答え」ではなく「問い」。

**次への橋渡し**: Silent Gaze が右へ収束して消える。**視界が閉じてから、Visionで開く。**

## Discovery — Vision

**作りたい状態**: 自分の視界が開いていく感覚。

ここでユーザーは初めて **「見る主体」** になる。スクロールが視界の変化と一致するため、動かしているのは自分だと分かる。
Silent Gaze の視線を借りる体験が完成する地点。

**次への橋渡し**: 視界が開いた状態のまま、What We Can Do の「対象」へ視線が向かう。

## Trust — What We Can Do

**作りたい状態**: この会社は車を見極める力がある、と信じる。

Trustは主張では生まれない。**見ている対象の順序**で生まれる。
全体 → 形 → 顔 → 足回り → 内部 → 損傷 → 運搬 → 整備 → 再利用 → 未来。
**外から内へ、見えるものから見えないものへ進む順序そのもの**が、「この会社は表面で判断していない」という証明になる。

損傷した車を暗く重く見せながら、**「それでも価値は残っている」**へ着地させる。ここがブランドの核心。

**次への橋渡し**: **明転する。** 暗闇で見つけた価値を、光の下へ持ち出す。

## Possibility — Buy

**作りたい状態**: 自分の車にも次があるかもしれない、と思う。

Trust(この会社は分かっている)から Possibility(だから自分の車も)への移行。
**主語がForesightからユーザーへ移る**セクション。ここで初めて「あなたの車」の話になる。

「動かないなら、取りに行く。」が最も強い一行。**約束であり、差別化点。**

**次への橋渡し**: 買い取った車がどこへ行くのか、へ視線が移る。

## Confidence — Sell / Find

**作りたい状態**: この会社になら任せられる、と確信する。

Possibility(かもしれない)から Confidence(任せられる)へ。
**Sell** = 渡す姿勢を見せる。**Find** = 無いものまで探しに行く姿勢を見せる。
どちらも「台数」ではなく **「一台への向き合い方」** で確信を作る。

最も明るい `#FFFFFF` を Sell に置くのは、**次の人へ渡す瞬間がこの物語の頂点**だから。

**次への橋渡し**: 確信を得た状態で、静けさへ戻る。

## Action — CTA

**作りたい状態**: 相談してみよう、と思う。

**暗転して静かに終わる。** 最後まで明るく騒がしいと、行動が「勢い」になる。
Foresightが求めるのは勢いではなく **納得した上での一歩**。だから静けさへ戻す。

「動かない。古い。傷がある。価値がわからない。—— それでも大丈夫です。」
ここで **Loading の Darkness と呼応する**。分からない状態から始まり、分からなくても大丈夫、で終わる。**円環が閉じる。**

---

## 設計判断への使い方

| 迷い | 判断基準 |
|---|---|
| この演出を入れるべきか | **担当感情を強めるか?** 強めないなら削る |
| ここに情報を足すべきか | Curiosity区間なら**足さない**(答えを与えると好奇心が死ぬ) |
| ここを明るくすべきか | 感情曲線と明度が**同じ向き**か確認する |
| 静止時間が長すぎないか | Darkness / Discovery では**静止こそが感情を作る**。長さは正当 |
| CTAをもっと目立たせるべきか | Action は**静けさの中の一歩**。目立たせると勢いになり、ブランドが変質する |

**最も注意すべき失敗**: Curiosity(Hero)で説明しすぎること。
ここで全部分かってしまうと、以降の Discovery / Trust / Possibility が**すべて確認作業に変わる**。映画が終わる。
