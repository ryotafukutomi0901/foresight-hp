# Lighting Bible

> **光と質感の数値の唯一の出典。** 値は `lib/tokens.ts` の `lighting` に反映する。

## 原則

1. **光源オブジェクトは置かない。** このシーンに `directionalLight` も `pointLight` も無い。素材はすべて自発光(`MeshBasicMaterial` + 加算合成)で、**光は「素材の明るさ」と「霧への散乱」だけで作る**。物理ライトを足すと計算負荷に見合わず、モノクロでは差も出ない。
2. **黒を潰さない。** 地は `#090909`。純黒(`#000000`)にすると階調の下限が無くなり、フォグとグレインの効きが死ぬ。
3. **白飛びさせない。** 加算合成 + Bloom は容易に画面を白く飽和させる。**露出は「足りないくらい」で止める。**

---

## Light Color

| トークン | 値 | 用途 |
|---|---|---|
| `fogColor` | `#090909` | シーンのフォグ色。Color System の地と一致させる |
| `clearColor` | `#090909` (alpha 0) | 背後のDOM背景を透かす |
| `emissive` | `#FFFFFF` | 素材の自発光。**モノクロなので色温度は振らない** |

**色温度を振らない理由**: High Gloss Mono は完全な中立グレー(R=G=B)。*Sharp / technology-forward* という定義に対し、暖色・寒色を混ぜると方向が逆になる。

## Exposure / Tone Mapping

| トークン | 値 |
|---|---|
| `toneMapping` | `ACESFilmic` |
| `toneMappingExposure` | `1.0` |

ACESFilmic を使う理由: 加算合成でハイライトが 1.0 を超えたとき、線形だと即座に白飛びする。ACES は上限付近をロールオフするため、**明るい部分に階調が残る**。これがCGを「映像」側へ寄せる。

## Fog

| トークン | 値 |
|---|---|
| `fog.type` | `FogExp2` |
| `fog.density` | `0.014` |

指数フォグ。**線形フォグ(`Fog`)を使わない理由**: 開始・終了距離を持つため「霧が始まる面」が見えてしまう。指数なら境界が存在しない。

## Bloom

| トークン | 値 | なぜ |
|---|---|---|
| `bloom.intensity` | `0.35` | |
| `bloom.luminanceThreshold` | `0.62` | **閾値を高く取り、線画の白だけを拾う。** 下げると霧まで光って画面が白飛びする(実測で確認済み) |
| `bloom.luminanceSmoothing` | `0.3` | |
| `bloom.mipmapBlur` | `true` | |

初期値 `intensity 0.72 / threshold 0.28` では画面全体が白い塊になり文字が読めなかった。**Bloomは効かせるより抑える方が難しい。**

## Noise（フィルムグレイン）

| トークン | 値 |
|---|---|
| `noise.opacity` | `0.2` |
| `noise.blendFunction` | `SOFT_LIGHT` |
| `noise.premultiply` | `true` |

**このサイトで最も費用対効果が高いエフェクト。** グレインが入るだけでCGが映像側に寄る。
`SOFT_LIGHT` を使う理由: `NORMAL` だと暗部が持ち上がって黒が濁る。ソフトライトなら**黒を保ったまま粒状感だけ乗る**。

さらに: 素材の実解像度が267pxしかない現状、**グレインは粗を「意図した粒状感」に変換する役割も担う**。素材が高解像度化しても粒度を調整すれば残す価値がある。

## Vignette

| トークン | 値 |
|---|---|
| `vignette.offset` | `0.22` |
| `vignette.darkness` | `0.92` |
| `vignette.eskil` | `false` |

画面の縁を落として中央へ視線を集める。**「見通す」ブランドに対して、視野の縁が暗いのは意味論的にも正しい。**

## Chromatic Aberration

| トークン | 値 |
|---|---|
| `ca.offsetBase` | `[0.0004, 0.00024]` |
| `ca.offsetMax` | `[0.0026, 0.0016]` |
| `ca.radialModulation` | `true` |
| `ca.modulationOffset` | `0.3` |

**速く動いたときだけ滲む。** 常時掛けると安っぽくなる。スクロール速度に連動させ、静止時はほぼゼロ。

## Ambient / Reflection / Shadow

| 項目 | 方針 |
|---|---|
| Ambient | **使わない**(自発光のため不要) |
| Reflection | **リアルタイム反射は使わない。** 反射は素材側(Reflection Pack)で表現し、実行時コストをゼロにする |
| Shadow | **シャドウマップを使わない。** 光源が無いため落ちる影も存在しない。接地感が要る箇所は素材側(Shadow Pack)で持つ |

**なぜ実行時ではなく素材で持つか**: モノクロ・自発光の画づくりでは、リアルタイム反射/影の計算結果と素材の質感が一致せず、かえって浮く。素材に焼き込む方が絵として強く、かつ軽い。

## Contrast

Color System(5色)を参照。**光の側でコントラストを作らない。**
明度差は色トークンで持ち、Lighting は「空気」だけを担当する。責務を分けないと、どちらを触っても画が変わる状態になり調整不能になる。
