# Motion Bible

> **このファイルはモーション数値の唯一の出典。** Design System・Storyboard・Shot List は数値を再掲せず、ここを参照する。
> 値は `lib/tokens.ts` の `motion` にそのまま反映する。

## 原則

1. **すべてを同じ ease で動かさない。** 用途ごとにカーブを分ける。同一 ease の多用は「テンプレートで作った」印象に直結する。
2. **名前は役割で付ける。** 呼び出し側がベジェ数値を直接書かない。数値を変えたいときに全箇所を追う羽目になるため。
3. **サイトの背骨は「奥から手前へ」。** 要素は下からせり上がるのではなく、奥(小さくぼけた状態)から手前(原寸・鮮明)へ来る。カメラが前進しているという一貫した嘘を、全セクションで守る。

## Ease

| トークン | cubic-bezier | 用途 | なぜ |
|---|---|---|---|
| `out` | `0.16, 1, 0.3, 1` | 入場全般 | 速く動き出し、ゆっくり着地する。要素が「置かれた」感じが出る |
| `inOut` | `0.76, 0, 0.24, 1` | 場面転換・罫線 | 対称の加速→減速。始点と終点が等価な動きに使う |
| `heavy` | `0.34, 0, 0.2, 1` | BUY の見出し | 動き出しが重く、止まり際に粘る。「走れなくても終わりじゃない」の重量感 |
| `snap` | `0.2, 0.9, 0.1, 1` | 決定・発見 | 一気に到達して微かに落ち着く。Find の「見つかった」瞬間 |
| `dolly` | `0.45, 0.05, 0.25, 1` | カメラの引き | 中盤を持続させ、通過の過程を読ませる |
| `dive` | `0.6, 0, 0.9, 0.35` | 目の中へ入る | **最後まで加速し続ける。** 減速すると「止まって見え」、入っていく感覚が消える |
| `linear` | `none` | scrub連動 | スクロール量と1:1で対応させる箇所は必ずこれ。ease を掛けるとスクロールと画面がズレて酔う |

`dive` だけが減速しない例外。**没入の方向(入る)を担うカーブなので、他と混ぜない。**

## Duration（秒）

| トークン | 値 | 用途 |
|---|---|---|
| `micro` | `0.3` | ホバー・フォーカス |
| `ui` | `0.6` | UI状態変化 |
| `enter` | `1.0` | 要素の入場 |
| `cine` | `1.6` | シネマティックな移動・罫線 |
| `hold` | `0.4` | **静止**。次の動きまで意図的に何も起こさない時間 |

`hold` を独立トークンにしている理由: 実装ポリシーの「静止時間を恐れない」を、感覚ではなく数値として持つため。**間を空ける判断を毎回ゼロから迷わない。**

## 変形量

| トークン | 値 | 備考 |
|---|---|---|
| `opacity.from` | `0` | 入場の始点 |
| `opacity.ghost` | `0.06` | 背景に沈む装飾の上限 |
| `scale.layerFrom` | `0.94` | 奥から来る要素の初期値。これ以上小さいと「縮んでいる」に見える |
| `scale.corridorMax` | `1.6` | **回廊の拡大上限(厳守)。** 素材267pxが破綻する境界。CEO指摘 |
| `blur.layerFrom` | `8px` | 奥にある状態 |
| `blur.deepFrom` | `20px` | 霧の中から結像する場合 |
| `y.layerFrom` | `40px` | 奥から手前への移動量 |
| `yPercent.mask` | `110` | 行マスクの外へ完全に逃がす量 |
| `rotateX.charFrom` | `-78deg` | 文字が倒れた状態。明朝の面積を活かす |
| `letterSpacing.trackFrom` | `0.5em` | 字間が開いた状態から締める |

## reduced-motion

`prefers-reduced-motion: reduce` のとき **モーションを遅くするのではなく、最終状態を即座に適用する。** 遅い動きは酔いの原因になるため、「弱める」のではなく「無くす」。3Dは起動しない。
