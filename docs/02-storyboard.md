# Storyboard — Loading から CTA までを一本の映画として

> 数値は各Bibleを参照。ここでは**構成と繋がり**を定義する。
> Shot単位の詳細は `shot-list.md`(Phase 3で作成)。

## IA 確定事項

| セクション | 現行実装 | 決定 |
|---|---|---|
| Loading | `OpeningSequence` | 5.0秒に短縮。Flipで Hero へ接続 |
| Hero | `Hero` | **独立した舞台として設計。回廊素材は使わない** |
| Vision | `Vision` | **変更しない** |
| What We Can Do | PHILOSOPHY + UNSEEN + NARRATIVE | **3つを1楽章へ統合** |
| Buy | `Buy` | 明転 |
| Sell | `Sell` | 明転(最も明るい) |
| Find | `Auction` | **Find へ改名**(「探す」が事業実態。AUCTIONは手段名) |
| CTA | `Contact` | 暗転して静かに終わる |

### なぜ3セクションを統合するか

PHILOSOPHY(状態の先を見る)/ UNSEEN(不動車・事故車…)/ NARRATIVE(10枚の物語)は、
**同じ主張を3回繰り返していた**。読み手には「まだこの話?」に見える。

統合後は **1つの楽章の中で「宣言 → 列挙 → 実証」** の3楽節として機能させる。
主張は1回、そのあと証拠を積む構造にする。

## 全体の流れ

```
Loading    Darkness    #090909   5.0s
   ↓  Flip（ロゴが中央→ヘッダー左上へ）
Hero       Curiosity   #090909   通過（pinしない）
   ↓  Silent Gaze が右へ収束して消える（視界が閉じる）
Vision     Discovery   #090909   pin（変更しない）
   ↓  視界が開いた状態のまま対象へ視線が向かう
WhatWeCanDo Trust      #2F2F2F   最長区間
   ↓  ★明転（暗闇で見つけた価値を光の下へ）
Buy        Possibility #F2F2F2
   ↓
Sell       Confidence  #FFFFFF   物語の頂点
   ↓
Find       Confidence  #CFCFCF
   ↓  ★暗転（静けさへ戻る）
CTA        Action      #090909
```

## 1. Loading

| | |
|---|---|
| **感情目標** | Darkness — 何も見えない。しかし何かがあると感じる |
| **前からの受け** | (先頭) |
| **次への渡し** | ロゴが Flip でヘッダーへ移動。**Loadingは別物ではなくページの一部だったと理解させる** |

**スクロール体験**: スクロールしない。5.0秒の固定尺。Esc / SKIP で中断可。

**Camera**: 3Dなし。DOM変形のみ。ロゴ内の目を原点に指数拡大。
**Lighting**: 背景 `#090909`。瞳の闇へ向かう放射状ストリーク。
**Typography**: なし(ロゴのみ)。
**Motion**: `dive` ease(最後まで加速)。→ [Motion Bible](./motion-bible.md)

**使用素材**: `logo.svg`(要提供)/ 雲4点(既存)

```
┌────────────────────────────────┐
│                          SKIP  │
│                                │
│                                │
│          ╭─────────╮           │
│          │ FORESIGHT│  ← 目に   │
│          ╰─────────╯     入る   │
│                                │
│                                │
└────────────────────────────────┘
```

**受け入れ条件**: 5.0秒を長いと感じない / 2回目は再生されない / reduced-motionで非表示

## 2. Hero

| | |
|---|---|
| **感情目標** | Curiosity — 普通とは違う視点だと直感する。**説明しすぎない** |
| **前からの受け** | Flipの着地点。Loading最終フレームがそのまま初期状態 |
| **次への渡し** | Silent Gaze が右へ収束して消える。**視界が閉じてから Vision で開く** |

**スクロール体験**: pinしない。通過点。スクロール開始で層が分離しVisionへ。

**Camera**: **3Dなし**(→ [Hero Bible](./hero-bible.md) D-008)。ポインタ追従パララックスのみ。
**Lighting**: 光源はSilent Gazeの線のみ。
**Typography**: `display-xl` 2行。**文字単位アニメは使わない**(技巧が先に見えるため)。
**Motion**: 行マスクで立ち上げ。線は周期6秒で明滅。

**使用素材**: `logo.svg` のみ。**車両素材は一切使わない(規律1)**

```
┌────────────────────────────────┐
│ [logo]      BUY SELL FIND CTA  │
│                                │
│  EVERY CAR HAS A NEXT.    ╱    │
│                          ╱     │
│  車の未来を、           ╱      │
│  見通す。              ╱       │
│                                │
│  どんな状態の車にも、           │
│  次の可能性がある。             │
│                                │
│  [車を売る→] [車を探す→]        │
│           SCROLL               │
└────────────────────────────────┘
   左50%: 文字      右50%: 空白と視線
```

**受け入れ条件**: WebGLコンテキスト0 / 回廊素材0枚 / `<h1>`1つ / Flipの継ぎ目が見えない

## 3. Vision

| | |
|---|---|
| **感情目標** | Discovery — 自分の視界が開いていく。**ここで初めて「見る主体」になる** |
| **前からの受け** | 閉じた視界から開く |
| **次への渡し** | 開いた視界のまま、対象へ視線が向かう |

**変更しない。** 既にCEO評価済み。現行の pin + 3D霧 + 3段の語をそのまま維持する。

**受け入れ条件**: **描画が変更前と完全に一致すること**(Playwrightで比較)

## 4. What We Can Do

| | |
|---|---|
| **感情目標** | Trust — 表面で判断していないと信じる |
| **前からの受け** | 開いた視界が対象を捉える |
| **次への渡し** | **明転。** 暗闇で見つけた価値を光の下へ持ち出す |

**3楽節構成**(統合後)

| 楽節 | 内容 | 由来 |
|---|---|---|
| **宣言** | SEE BEYOND THE CONDITION. / どんな状態の車にも、次の可能性がある。 | PHILOSOPHY |
| **列挙** | 不動車。事故車。長年乗り続けた車。価値がわからない車。→ それでも、次がある。 | UNSEEN |
| **実証** | 10枚の3D回廊(全体→形→顔→足回り→内部→損傷→運搬→整備→再利用→未来) | NARRATIVE |

**スクロール体験**: 最長区間。スクロール = カメラが回廊を前進。
**Camera**: 回廊を通過。**`nearCut -14` / 拡大率1.6倍上限を厳守**(CEO指摘)。
**Lighting**: `#2F2F2F` — 闇が一段持ち上がる。
**Typography**: 文字単位アニメ・字間アニメをここで解禁。
**Material**: **ディザリング**。`pixelSize` を距離連動。

**使用素材**: 車両10点(既存 or 高解像度版)

```
┌────────────────────────────────┐
│                                │
│   SEE BEYOND                   │  宣言
│   THE CONDITION.               │
│                                │
├────────────────────────────────┤
│         不動車。                │  列挙（1語ずつ）
├────────────────────────────────┤
│    ╱▔▔▔╲                       │
│   │ 車両 │ ← 3D回廊を通過      │  実証
│    ╲___╱      THE WHOLE        │
│              力強く無骨な…      │
└────────────────────────────────┘
```

**受け入れ条件**: 画像ギャラリーに見えない / 損傷が「価値がない」に見えない / 拡大率1.6倍以下

## 5. Buy

| | |
|---|---|
| **感情目標** | Possibility — 自分の車にも次があるかもしれない。**主語がユーザーへ移る** |
| **前からの受け** | **明転**。3Dがフェードアウト |
| **次への渡し** | 買い取った車がどこへ行くのかへ |

**Camera**: **3D停止。** タイポグラフィだけの章。
**Lighting**: `#F2F2F2` 地 / `#090909` 文字。
**Motion**: `heavy` ease。「走れなくても、終わりじゃない。」を重く立ち上げる。

**核**: 「動かないなら、取りに行く。」を**前後に大きな余白を取って独立配置**。

```
┌────────────────────────────────┐ ← #F2F2F2
│ 01  BUY ─────────────────────  │
│                                │
│  走れなくても、    不動車。事故車。│
│  終わりじゃない。   故障車。…     │
│                                │
│  ──────────────────────────    │
│                                │
│  動かないなら、                 │ ← 核（独立）
│  取りに行く。                   │
│                                │
│  [ 車を売る → ]                 │
└────────────────────────────────┘
```

**受け入れ条件**: 不動車の所有者が問い合わせようと思う / 3Dが停止している

## 6. Sell

| | |
|---|---|
| **感情目標** | Confidence — 任せられる。**物語の頂点** |
| **前からの受け** | 買い取った車の行き先 |
| **次への渡し** | 無い車はどうするのか、へ |

**Lighting**: `#FFFFFF` — **サイト中で最も明るい。次の人へ渡す瞬間が頂点だから**
**Motion**: 水平の受け渡し(左→右)。モバイルは縦へ置換。

**在庫一覧は作らない。** 実データが無いため。姿勢(見極める/整える/つなぐ)で伝える。

**受け入れ条件**: 台数を競って見えない / 在庫一覧が無いことに不満が出ない

## 7. Find

| | |
|---|---|
| **感情目標** | Confidence — 無いものまで探しに行く |
| **前からの受け** | 「ここに無い車は?」という問い |
| **次への渡し** | **暗転**。静けさへ戻る |

**Lighting**: `#CFCFCF`。明部の中で最も沈み、CTAの暗転へ橋渡しする。
**Motion**: `snap` ease。走査線が横断し、通過後に要素が解像する。

**「オークション代行」を手段名として前に出さない。** 価値は「探す」。

**受け入れ条件**: 手順説明に見えない / 欲しい車が無い人でも相談したくなる

## 8. CTA

| | |
|---|---|
| **感情目標** | Action — 静けさの中の一歩 |
| **前からの受け** | **暗転** |
| **次への渡し** | (終端) **Loadingの Darkness と呼応し円環が閉じる** |

**Lighting**: `#090909` へ戻る。3D再開(軽量)。
**Motion**: 減速して静止。装飾を削ぎ落とす。

「動かない。古い。傷がある。価値がわからない。—— それでも大丈夫です。」

**受け入れ条件**: 査定を強要される感じがしない / 送信できたか確実に分かる / フォームがキーボードで完走できる

## 繋ぎの一覧（Consistency Rule）

**各セクションは単体で完成させない。** 繋ぎが設計の本体。

| 継ぎ目 | 手法 | 守るもの |
|---|---|---|
| Loading → Hero | **GSAP Flip**(ロゴ中央→ヘッダー) | Loadingがページの一部だと分かる |
| Hero → Vision | Silent Gaze が収束して消える | **閉じてから開く**順序 |
| Vision → WhatWeCanDo | 視界が開いたまま対象へ | 主体の連続性 |
| WhatWeCanDo → Buy | **明転** + 3Dフェードアウト | 暗闇→光の物語 |
| Buy → Sell | 明度が上がる | 頂点へ向かう |
| Sell → Find | 明度が下がり始める | 暗転の予告 |
| Find → CTA | **暗転** + 3D再開 | 円環が閉じる |

**明転・暗転は各1回ずつ。** 何度も反転させると章立てが読めなくなる。
