# Experience KPI

> **「どんな実装か」ではなく「ユーザーにどんな体験を与えるか」を成功基準にする。**
> 実装の完了 ≠ 体験の完成。ここが満たせていなければ、コードが動いていても未完成とみなす。

各セクションに **目的 / 成功条件 / 失敗のサイン** を定義する。
「失敗のサイン」を併記するのは、成功条件だけだと**都合よく解釈できてしまう**ため。

---

## Loading

**目的**: ブランドへの期待感を作る。

| 成功条件 | 失敗のサイン |
|---|---|
| 長いと感じない | スキップボタンを探す |
| Heroへの期待が高まる | 「早く終われ」と思う |
| 何かを"見せられた"ではなく"入っていった"感覚が残る | ただのロゴアニメに見える |
| 2回目以降は再生されないと分かる | 再訪のたびに待たされる |

**判定**: 5.0秒を長いと感じさせないこと。**スキップ率が高ければ失敗**。

## Hero

**目的**: 5秒以内にブランドを理解できる。

| 成功条件 | 失敗のサイン |
|---|---|
| 何の会社か伝わる | 「何屋さんか分からない」 |
| 続きを見たくなる | スクロールせず離脱 |
| Loadingと地続きだと感じる | Loadingが「別物」に見える |
| 静かだが弱くない | 情報が薄くて手抜きに見える |

**判定**: 「車の未来を、見通す。」を読んで**中古車の会社だと分かり、かつ普通の中古車屋ではないと感じる**こと。両立が条件。

## Vision

**目的**: 「見る」という行為そのものを体験させる。

| 成功条件 | 失敗のサイン |
|---|---|
| 視界が開いていく感覚がある | ただ文字が出てくるだけに見える |
| スクロールが「進む」感覚と一致する | スクロールしても何も起きない区間がある |
| 3Dが技巧として目立たない | 「3Dすごい」が先に来る |

**判定**: **変更しない(現状維持)。** 既にCEO評価済みのため、この基準は現状の追認。

## What We Can Do

**目的**: 車の状態ではなく、その先の可能性を見る会社だと理解させる。

| 成功条件 | 失敗のサイン |
|---|---|
| 一台の車が次へ進む物語として読める | 画像ギャラリーに見える |
| 「見る → その先を見る → 価値を戻す → 次へ」の順序が体感できる | どこを見ているか分からなくなる |
| 損傷した車を「価値がない」と感じない | 暗く重いだけの印象になる |
| 車両に寄っても画質が破綻しない | 粗が見えて安っぽくなる |

**判定**: スクロールし終えたとき **「この会社は車を単なる中古車として見ていない」** と感じること。

## Buy

**目的**: どんな状態でも売れると確信させる。

| 成功条件 | 失敗のサイン |
|---|---|
| 自分の車も対象だと思える | 「うちのはダメだろう」と思う |
| 「動かないなら、取りに行く。」が刺さる | 他の情報に埋もれて読み飛ばされる |
| 明転して情報が読みやすい | 暗いままで読みにくい |

**判定**: **不動車を持っている人が問い合わせようと思うこと。** ここが最も強い行動セクション。

## Sell

**目的**: 在庫ではなく「次のオーナーを待つ車」だと伝える。

| 成功条件 | 失敗のサイン |
|---|---|
| 一台ずつ見極めている姿勢が伝わる | 台数を競っているように見える |
| 中古車ポータルと違うと感じる | 大量のカードUIに見える |

**判定**: **在庫一覧が無いことに不満を感じないこと。** 無くても姿勢が伝われば成功。

## Find

**目的**: まだ市場にない一台まで探しに行けると伝える。

| 成功条件 | 失敗のサイン |
|---|---|
| 「探してもらえる」と分かる | オークション代行の手順説明に見える |
| 欲しい車が無い人でも相談したくなる | 自分には関係ないと感じる |

**判定**: **「オークション代行」という手段名ではなく「探す」という価値**として受け取られること。

## CTA

**目的**: どんな状態でも相談していいと背中を押す。

| 成功条件 | 失敗のサイン |
|---|---|
| 相談のハードルが下がる | 査定を強要されそうに感じる |
| 暗転して静かに終わる | 最後まで騒がしい |
| 送信できたか確実に分かる | 送ったか不明なまま終わる |

**判定**: **「価値がわからない」状態の人が、それでも問い合わせようと思うこと。**

---

## 全体を通したKPI

| 指標 | 目標 |
|---|---|
| **一本の映画として繋がっているか** | セクションの切れ目で「別ページに来た」と感じない |
| **スクロール量と情報量が一致しているか** | 「長いだけで何もない」区間が無い |
| **技巧が先に見えていないか** | 「3Dすごい」より先に「この会社いいな」が来る |
| **静止時間が不安にならないか** | 何も動かない瞬間が「間」として機能する |
| **モバイルで劣化していないか** | PCと同じ体験。寸法だけが違う |

**最上位の判定**: 見終わったユーザーが **「車の状態ではなく、その先の可能性を見ている会社だ」** と言語化できること。
