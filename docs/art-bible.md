# Art Bible

> ブランド全体で統一する視覚ルール。数値のうちモーション/カメラ/光に属するものは各Bibleを参照し、ここでは重複させない。

## Silent Gaze — この画づくりの一行

> **見る主体はユーザーではなく、Foresightの視線である。ユーザーはその視線を借りる。**

鷹は実体として登場しない。存在するのは「見通す視線」だけ。
したがって画面には**主語が写らない**。写るのは、視線が捉えた対象と、その周囲の空気。

## Contrast

| 対 | 比率 | 用途 |
|---|---|---|
| `#F2F2F2` / `#090909` | 17.4:1 | DARK本文 |
| `#CFCFCF` / `#090909` | 12.6:1 | DARK補助 |
| `#090909` / `#F2F2F2` | 17.4:1 | LIGHT本文 |
| `#2F2F2F` / `#F2F2F2` | 11.2:1 | LIGHT補助 |

**全対がAAA。** モノクロで色に頼れない以上、コントラストは唯一の階層手段。ここを妥協すると読めないサイトになる。

**中間調を本文に使わない。** `#CFCFCF` と `#2F2F2F` の間には本文用の色を置かない。5色構成を守るためだけでなく、中間調の文字は「読ませる気がない」印象を与えるため。

## Noise / Film Grain

- グレインは **全画面に均一に**掛ける。部分的に掛けると合成に見える
- 強度は [Lighting Bible](./lighting-bible.md) の `noise.opacity`
- **粒は動かし続ける。** 静止したグレインはテクスチャに見え、フィルムに見えない

## Dithering（ブランドの視覚言語）

ディザリングは装飾ではなく **Foresightの視覚言語そのもの**。

| 項目 | 決定 | 値 |
|---|---|---|
| 方式 | Bayer 4×4 の順序ディザ | `matrixSize 4` |
| 適用対象 | 車両素材・背景素材(テキストには掛けない) | — |
| `pixelSize` | **カメラ距離に連動**させる | 遠 `0.8` → 近 `1.6` |
| 暗部カットオフ | この輝度未満は**完全な黒**として扱う | `0.16` |
| 明部カットオフ | この輝度以上は**完全な白**として扱う | `0.94` |

### 粒の大きさは「様式が被写体を殺さない」範囲に収める

初回実装で `pixelSize` を 近 `3.5` / 遠 `1.0` にしたところ、
**車両が判別不能な粒の塊になった**(実測)。これはディザリングの目的から外れている。

> ディザリングは**被写体を様式化する**ものであって、**消すもの**ではない。
> 「格好良さのためだけの演出」に転落する典型なので、粒の大きさは常に
> **被写体が何であるか分かる**ことを上限とする。

→ 近 `1.6` / 遠 `0.8` に下げ、線画の構造を保ったまま粒状感だけを乗せる。

### 2値化しない — 原画とディザを混ぜる

**線画を完全に2値化してはいけない。**

素材は267pxのアンチエイリアス付き線画で、線幅は1〜2px。
2値化すると**線の縁の中間調が点に分解され、線そのものが壊れる**(実測)。
粒を細かくしても解決しない。解像度が足りていないため原理的に破綻する。

したがって **`mix(原画, ディザ, strength)`** で混ぜる。

| トークン | 値 | 意味 |
|---|---|---|
| `ditherStrength` | `0.35` | ディザの混合比。0=原画のまま / 1=完全2値化 |

**0.35 とする理由**: 粒状の質感は明確に感じられるが、線の連続性は保たれる境界。
これ以上上げると線が途切れ始め、下げるとディザだと分からなくなる。

> ブランドの視覚言語としてのディザリングは維持する。
> **変えるのは「どう適用するか」であって「使うかどうか」ではない。**
> 高解像度素材(4096px)に差し替わった後は `strength` を上げる余地がある。

### 暗部カットオフが必要な理由

素材の黒背景はテクスチャ圧縮とミップマップにより**厳密な 0 ではない**。
カットオフ無しだと、本来黒であるはずの背景にディザの白点が散り、
**プレーンの矩形が画面に浮かび上がる**(実測)。

加算合成では黒 = 透明なので、**黒を確実に 0 に落とすことが透過の前提**になる。
`0.16` は、素材の圧縮ノイズを吸収しつつ線画の暗部ディテールを残す実測値。

**なぜ距離連動か**: 寄るほど粒が粗くなる。結果として**解像度不足が「意図した粒状感」として読める**。素材の限界を様式に変換する仕掛けであり、高解像度素材に差し替わった後も表現として残す価値がある。

**テキストに掛けない理由**: 可読性が落ちるうえ、和文明朝の細い横画がディザで消える。

## Reflection / Metal / Glass

いずれも**実行時計算をしない**([Lighting Bible](./lighting-bible.md) 参照)。素材側で表現する。

| 質感 | 表現方針 |
|---|---|
| Metal | ハイライトを線で描く。面で光らせない。工業製品の硬さは「エッジの鋭さ」で出る |
| Glass | 透過を描かず、**反射だけ**を描く。モノクロで透過を表現すると濁る |
| Paint | ボディの曲面は**等高線状のハイライト**で示す。グラデーションで塗らない |

## Shadow

落ち影は使わない。**接地は「その下だけ暗い」ではなく「その周囲の霧が薄い」で表現する。**
光源が無い世界観のため、影があると嘘になる。

## Spacing

4pxを基数とする。`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128 / 160 / 200`

| 用途 | 値 |
|---|---|
| セクション上下 | `clamp(6rem, 14vh, 12rem)` |
| コンテナ最大幅 | `1440px` |
| ガター | `clamp(1.25rem, 5vw, 5rem)` |

**余白は「余り」ではなく要素。** 詰めれば情報が増えるが、Foresightの静けさは余白そのものが作っている。

## Rhythm

**アニメーションよりリズムを優先する。**

1画面には **強い主張を1つだけ**置く。2つ以上あると視線が迷い、映画ではなくカタログになる。
セクション内は `動 → 静 → 動` の3拍で構成する。静(`hold` = 0.4s)を挟まないと、動きが連続して意味を失う。

## Depth

奥行きは4層で管理する。

| 層 | 内容 | 動き |
|---|---|---|
| 0 | 3D空間(霧・塵・回廊) | カメラ前進に連動 |
| 1 | 大型タイポグラフィ | パララックス `±8%` |
| 2 | 本文・キャプション | パララックス `±4%` |
| 3 | UI(ヘッダー・CTA) | 固定 |

**層を跨いだ要素を作らない。** 「本文だけど3D空間にある」ようなものを1つ作ると、以後すべての判断が崩れる。

## Negative Space

- ファーストビューの**50%以上を空ける**
- 大型タイポグラフィの周囲には、その文字高の**1.5倍以上**の余白を確保する
- **空白を埋めたくなったら、情報が足りないのではなく主張が多すぎることを疑う**

## Visual Weight

重さの順位を固定する。

```
1. 大型和文タイポグラフィ（最重）
2. 車両ビジュアル
3. 欧文ラベル（トラッキング広め）
4. 本文
5. 罫線（最軽）
```

**この順位を反転させない。** 例えば罫線を太くして目立たせたくなった時点で、階層設計が失敗している。
