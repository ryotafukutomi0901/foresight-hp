## 1. 座標系・単位（厳守）

```
1 Blender unit = 1 three.js unit = 1 メートル

+X = 車両の右側
+Y = 上
+Z = 車両の後方（したがって前方は -Z）

ワールド原点 (0,0,0) = 4輪接地面の中央・地面の高さ
```

**注意**: Blenderの既定は Z-up だが、glTFエクスポート時に **Y-up へ変換**される
（`+Y Up` オプションを有効にすること）。上記は **three.js側（Y-up）での定義**。

エクスポート後、three.js上で `position=(0,0,0)` `rotation=(0,0,0)` に置いたとき、
**車両が地面に正しく接地し、カメラ（-Z方向にある）に対してフロントを向いている**
状態が正解。

## 2. オブジェクト名（完全一致・大文字小文字含む）

以下の20個。**この名前でBlenderのオブジェクト名を付けること。**
コード側は名前で参照するため、1文字でも違うと動かない。

```
Body            FrontBumper     RearBumper      Grill
Headlight_L     Headlight_R     Glass           Mirror_L
Mirror_R        Wheel_FL        Wheel_FR        Wheel_RL
Wheel_RR        RearGate        Door_FL         Door_FR
Door_RL         Door_RR         RoofRail        Interior
```

`_L` = 左（-X側） / `_R` = 右（+X側）
`FL` = 前左 / `FR` = 前右 / `RL` = 後左 / `RR` = 後右

### 階層構造

```
SUV (Empty, ルート)
├── Body
│   ├── FrontBumper
│   ├── RearBumper
│   ├── Grill
│   ├── Headlight_L
│   ├── Headlight_R
│   ├── Glass
│   ├── Mirror_L
│   ├── Mirror_R
│   ├── RoofRail
│   ├── Interior
│   ├── Door_FL / Door_FR / Door_RL / Door_RR
│   └── RearGate          ← 独立可動（§3）
├── Wheel_FL              ← 独立可動（§3）
├── Wheel_FR
├── Wheel_RL
└── Wheel_RR
```

**ホイールは Body の子にしない。** 車体が沈む（サスペンション表現）ときに
ホイールが一緒に沈むと接地しなくなるため、ルート直下に置く。

## 3. 可動パーツ（最重要）

**「rotationの値を変えるだけで正しく動く」ことが絶対条件。**
コード側は `object.rotation.x` に数値を代入するだけで、
位置補正・オフセット計算は一切行わない。

### RearGate（リアハッチ）

| | |
|---|---|
| Pivot位置 | **車体後端の上端・幅方向中央**（ヒンジの実位置） |
| 目安座標 | `(x=0, y=1.5, z=+2.4)` ※全長4.8m級の場合 |
| 回転軸 | **X軸のみ** |
| 閉状態 | `rotation.x = 0` |
| 全開状態 | `rotation.x = -1.2` rad（約 -69°、上へ跳ね上がる） |

Pivotがヒンジ位置に無いと、開いたときにハッチが車体から離れて浮く。
Blenderで「原点を3Dカーソルへ移動」してヒンジ位置に正確に合わせること。

### Wheel_FL / FR / RL / RR

| | |
|---|---|
| Pivot位置 | **各ホイールの回転中心**（円筒の軸上・中心） |
| 目安座標 | FL `(-0.85, 0.35, -1.55)` / FR `(0.85, 0.35, -1.55)` / RL `(-0.85, 0.35, 1.55)` / RR `(0.85, 0.35, 1.55)` |
| 回転軸 | **X軸のみ**（前進時は +X 方向に正回転） |

4本とも独立オブジェクト。Pivotがずれると、回転時にホイールが楕円を描いて破綻する。

### Headlight_L / R

| | |
|---|---|
| Pivot位置 | 各ライトの発光面中心 |
| 目安座標 | L `(-0.55, 0.75, -2.35)` / R `(0.55, 0.75, -2.35)` |
| 要件 | **Emissiveマテリアル。** Bloomのコアになる（§5） |

左右で独立して光量を変えられるよう、必ず別オブジェクトにすること。

## 4. ポリゴン数・最適化

| 項目 | 目標 |
|---|---|
| **総トライアングル数** | **〜5万**（2026-08-03 CEO承認で 1〜3万 から引き上げ。理由: 線画リファレンスへの忠実再現優先） |
| GLBファイルサイズ | 圧縮後 **5MB以内** |
| マテリアル数 | **最小限**（§5の5種類程度） |

> **予算変更メモ (2026-08-03)**: 「vehicle-parts線画の3D忠実再現」をCEOが優先方針として指示し、
> ポリゴン予算を 総1〜3万tri/3MB → **総5万tri/5MB** へ引き上げた。
> Pivot・オブジェクト名・座標系（§1〜§3）は凍結のまま変更しない。
> この引き上げに伴い **R3F側のFPSを `scripts/measure-fps.mjs` で実測**し、
> モバイルで問題が出れば再調整する（デシメート or LOD）こと。

- リアルタイム描画用。映像用のハイポリ（数十万tri）は不可
- 見えない面（車体内側、床下の細部）は削除
- N-gonを避け、四角面主体で構成
- Draco または Meshopt 圧縮を推奨

## 5. マテリアル（PBR）

| マテリアル | 対象 | 設定 |
|---|---|---|
| **Body** | Body, Bumper, RearGate, Door, Grill | PBR。metalness 0.6 / roughness 0.35。ボディカラーは**黒〜ダークグレー** |
| **Glass** | Glass | **透明**。opacity 0.25 / transmission 0.9 |
| **Headlight** | Headlight_L / R | **Emissive**（自己発光）。Bloomで滲ませる |
| **Chrome** | Mirror, RoofRail, ホイールリム等 | PBR。metalness 0.9 / roughness 0.15 |
| **Interior** | Interior | PBR。暗めのマット |

- サイトのブランドカラーは **黒 / 白 / モノクロ基調**。彩度の高い色は使わない
- テクスチャを使う場合、**1枚あたり最大 2048×2048**、合計24MB以内
- 可能ならテクスチャを使わずマテリアル設定のみで構成する（転送量削減）

## 7. 納品物

```
SUV.blend    -- 編集可能なマスターファイル
SUV.glb      -- Web配信用（+Y Up / Draco or Meshopt圧縮）
```

納品先: `public/models/SUV.glb`

### 納品後、コード側でやること

**1箇所だけ**。`components/three/vehicle/Vehicle.tsx` の

```ts
const USE_GLB = false;   // ← true にする
```

これで `VehiclePlaceholder` が `VehicleGLTF` に差し替わる。
呼び出し側（`VehicleScene.tsx`、各セクションの `useVehicleSegment`）は
**一切変更しない**。両者が同じ `VehicleHandle`（パーツ名 → Object3D）を
返す契約になっているため。

`VehicleGLTF` は §2 のオブジェクト名で GLB 内を検索する。
名前が欠けていると開発時にコンソールへ警告が出るので、
差し替え直後は必ずコンソールを確認すること。

## 9. 補足: なぜこの仕様が厳密なのか

このモデルは**サイトの主人公**であり、スクロールに完全同期して
以下を連続的に制御する。

```
Hero        右から走行 → 3/4ビューで停止 → サスペンション沈み込み → ヘッドライト点灯
Philosophy  時計回りに回転（フロント→側面→リア）→ リアハッチが開く → 荷室から光
Sell        ハッチを閉じる → 前進 → 側面へ → 車体をスキャンライトが走る
Buy         カメラが360度周回 → ホイール/グリル/ライトを順に見せる
Find        再び走行姿勢 → タイヤ回転 → 光のラインが分岐
Contact     減速 → タイヤ停止 → ヘッドライト消灯 → 静かに停止
```

**ユーザーが逆スクロールすると、これらが全て正確に巻き戻る。**
そのため「rotationの値を入れれば正しい絵になる」ことが構造的に必要で、
Pivotのズレは補正コードでは吸収しない方針（吸収すると逆再生で破綻するため）。
